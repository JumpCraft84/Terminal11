# Contributing to Terminal 11 Ultimate

Thanks for helping! Open an Issue to describe a bug or feature request. For code changes, fork the repository, make a focused change, test on your OS, and open a pull request with reproduction steps and screenshots when useful.

## Basic checks

```bash
python3 -m py_compile terminal11.py
```

If you can, test the GUI on Windows and Raspberry Pi OS Desktop. Please do not commit passwords, tokens, local settings, or generated files.
